# 📚 Dokumentasi Proyek Pondok Rahmat (Kostara)

Folder ini berisi seluruh dokumen panduan arsitektur, panduan desain, spesifikasi teknis, dan rencana deployment untuk sistem Pondok Rahmat.

---

### 📑 Daftar Panduan

1. **[Panduan Umum & Ketentuan Kos](PROJECT_GUIDELINES_KOS.md)**
   * Ketentuan identitas kos (Khusus Putri Samata, Gowa).
   * Fasilitas otentik kamar, kontak pengelola, dan aturan sewa.

2. **[Panduan Property Management System (PMS)](PROJECT_GUIDELINES_PMS.md)**
   * Logika bisnis manajemen kamar, penyewa, tagihan/invoice, dan komplain.
   * Alur verifikasi pembayaran dan kwitansi sewa.

3. **[Panduan Desain Frontend](DESIGN_RULES_FRONTEND.md)**
   * Standar visual Pondok Rahmat (Color palette, tipografi Plus Jakarta Sans, layout).
   * Prinsip responsivitas dan konsistensi antarmuka.

4. **[Rencana Arsitektur Backend](BACKEND_PLAN.md)**
   * Spesifikasi REST API Express.js, skema Prisma ORM, dan autentikasi JWT.
   * Middleware, rate limiting, dan struktur routing.

5. **[Rencana Deployment & Pemeliharaan VPS](PRODUCTION_DEPLOYMENT_PLAN.md)**
   * SOP deployment production ke VPS (Oracle Cloud / Ubuntu).
   * Konfigurasi Docker, Nginx reverse proxy, SSL, dan strategi backup database.
